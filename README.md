# PulseEvents

PulseEvents is a modular Minecraft plugin designed for creating, managing, and running dynamic in-game events with smooth control and real-time feedback.

## About

The plugin provides a structured system for handling events with announcements, countdowns, and live visual feedback directly in-game.

## Features

- Event management system
- Announcement and countdown support
- Live UI (BossBar, ActionBar, Titles)
- Multi-world support
- Clean and modular architecture

## Download

- [Modrinth: PulseEvents](https://modrinth.com/plugin/pulseevents)

## Purpose

To provide a flexible system for running dynamic events on Minecraft servers.
